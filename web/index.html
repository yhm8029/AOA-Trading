파일은 localhost 서버로만 전달되고, GitHub나 외부 서버에 올라가지 않습니다.

권장 파일 2개

① AOA_TradingView_2021_Package.zip 또는 연간 events.csv
② AOA_candle_analysis.zip (이름 뒤의 (1)도 가능)

2018~2021 주문은 캔들 ZIP 안의 order_context.csv로 읽습니다. 상세 TP/CUT 등은 제공된 이벤트 분류가 있는 경우에만 표시합니다.

또는 앱 폴더의 data/inbox에 파일을 넣은 뒤:

차트 읽는 법

① 포지션 선택 → ② 시간봉 선택 → ③ 주문 클릭

롱 진입·추가는 캔들 아래, 숏 진입·추가는 위에 표시합니다. 청산은 반대편에 표시합니다. 같은 캔들의 같은 방향 주문은 묶이며, 클릭하면 오른쪽에서 개별 주문을 볼 수 있습니다.

마커는 해당 시간봉의 시작 시각으로 대응합니다. 원본 시간은 잠정 UTC로 해석하고, 한국시간 설정은 표시만 바꿉니다.

주문 그룹 총량 ≠ 첫 체결 순간의 수량. 첫 체결가와 전체 주문 평균가는 구분됩니다. CLOSE에 잔량이 있으면 '대부분 정리'로 표시합니다. CUT·Flip·주요 진입 분류는 이전 연구의 사후 가설입니다.

빈 구간은 데이터가 없는 구간입니다. 상위 시간봉은 해당 시간봉의 1분 데이터가 전부 있을 때만 표시합니다. 없는 가격을 연결하거나 보간하지 않습니다.

거래량의 '직전 완성 1분'과 '체결이 발생한 1분의 최종 거래량'은 다릅니다. 후자는 당시 주문 순간에 알 수 없었던 사후 정보입니다.

전체 데이터가 많아도 요청당 10,000봉으로 나눠 읽습니다. 서비스 구독에 따른 과거 연도 제한은 없지만 원본 데이터와 PC 용량이 필요합니다.

이 버전은 매매 복기 도구입니다. 미래 수익 예측, 자동매매, 체결 틱 리플레이, 계좌 전체 레버리지 재계산은 하지 않습니다.
