# v0.3.2 — 포지션 최종 순손익률 연결

## 업데이트
새 실행 ZIP을 새 폴더에 풀고 start_windows.bat를 실행합니다. 기존 앱/local-data를 선택하면 주문·캔들·메모 사본을 보존합니다. 자동으로 열리는 새 탭의 v0.3.2를 사용합니다. Python 3.10 이상 필요. 별도 pip 설치 없음.

## 기존에 파일을 다 넣었는데 성과만 비어 있을 때
이전 버전은 주문/시세를 가져오면서 별도 episodes.csv/포지션 성과표를 건너뛰었습니다. 원본 업로드 파일을 보존하지 않았으므로 기존 DB만으로 건너뛴 수치를 되살릴 수 없습니다.

앱의 **손익자료 연결 / 보완**에서 이미 가진 **AOA_candle_analysis.zip을 한 번 다시 선택**하세요. 이번 파서는 같은 SHA 파일도 성과표/주문가격을 새로 검사하며 기존 시세와 메모를 지우지 않습니다. 명시적 BTC 손익 열을 찾지 못하면 검증 기록에 실제 헤더를 남깁니다.

직접 연결할 수 있는 자료:
- **AOA_거래분석_2018-2021.xlsx**: 포지션 시트의 최종 순손익·가격손익·수수료·펀딩·진입/청산 수량·시각. 파일명에 (1)이 있어도 됩니다.
- **AOA_XBTUSD_2021_events.csv**: 2021년 기존 이벤트에 보고된 최종 BTC 손익 및 평균가격.
- **episodes.csv**: 명시적인 net_pnl_btc 등 BTC 단위 열과 계약·ID가 필요합니다.
- 원래 분석 ZIP의 **orders.csv**: 개별 주문의 수량·inverse_vwap가 있으면 정확한 진입 계약가치 합산. 확인되지 않은 cost/단위를 추정하지 않습니다.

XLSX만으로는 분모가 없을 수 있습니다. 순손익 BTC는 연결하되 주문 평균가격/역수가중가격 자료를 함께 넣어야 % 계산까지 가능합니다. XLSX는 저장된 셀 값만 읽고 수식·매크로·외부 링크를 실행하지 않습니다.

## 표시
- 오른쪽 맨 위 **포지션 최종 결과**: 순손익률 %와 순손익 BTC.
- 왼쪽 거래 목록: 동일한 순손익률.
- 마지막 청산 봉: 최종 성과 마커. 해당 실제 봉이 없으면 다른 봉에 임의로 붙이지 않습니다.
- 복기: 최종 체결이 끝날 때까지 결과를 숨기고 종료 후 공개.
- 계산식/비용/출처/분모 근거 확인 및 성과 JSON 저장.

## 산식과 검증 수준
**순손익률 = 제공된 최종 순손익 BTC / 누적 진입 계약가치 BTC × 100**.
XBTUSD: 진입 전체 체결의 Σ(수량/체결가격). 역수가중 평균가격이 있는 주문은 Q/inverse_vwap로 정확히 합산합니다. 진입/감량을 되풀이한 경우 재진입도 분모에 다시 포함됩니다. 증거금·실제 투입자본·계좌 수익률·연율 수익률이 아닙니다.

최종 순손익 = 가격손익 − 거래수수료 − 펀딩비. 음수 수수료/펀딩은 수취입니다. 세부 비용이 없으면 0으로 채우지 않습니다. 같은 순손익이 여러 주문에 반복되어도 한 번만 사용합니다.

**정확 계산 표시**: 포지션 원장 수량 합계와 주문 수량이 일치하고 역수가중가격/명시적 BTC 계약가치가 있는 경우, 또는 완결된 성과표에 명시적 누적 진입가치가 있는 경우.
**≈ 참고 표시**: 순손익은 제공값이지만 산술평균 가격을 분모 계산에 쓰거나 주문 전체성이 원장으로 검증되지 않은 경우. 확정 수익률과 구분합니다.
**계산 보류**: 알려진 수량 누락·서로 다른 손익/계약/시각 연결 충돌·미종료·분모 미확보. 이유와 연결 버튼을 표시합니다. Binance 시세/가상 레버리지를 끌어와 수익률을 만들지 않습니다.

명시적 BTC 분모가 없는 ETHUSD/기타 계약에는 XBTUSD 역계약 산식을 적용하지 않습니다. 증거금을 직접 입력한 경우의 참고 ROI는 별도 항목입니다.

## 검사 범위
Windows/Linux 단위검사와 5종 Chromium 동작검사, 배포 ZIP 실행검사를 수행합니다. 새 회귀에는 수수료·펀딩·리베이트·0손익·분모 근사·수량 부족·연결 충돌·기존 파일 재가져오기·XLSX 저장값·복기 종료 후 공개가 포함됩니다.
**거래 회귀자료는 합성 데이터입니다. 사용자의 원본 전체 거래자료를 CI에 업로드하거나 전수 검산한 것이 아닙니다.** 실제 자료의 정확한 연결 수준은 각 포지션의 검증 항목에 나옵니다.
