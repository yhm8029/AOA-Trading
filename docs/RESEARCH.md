# 연구 원칙

이 앱은 제공된 프로젝트 지침 중 시각화·기록의 정확성을 우선 구현한다. 단순 승률 맞히기보다 **진입 → 추가 → 감량 → 종료**의 과정을 본다.

1. 원본 거래기록이 최우선이고 기존 분석 보고서는 검증 대상이다.
2. 사실(체결·수량·가격)과 추론(왜 했는가, CUT/FLIP 의미)을 분리한다.
3. 단순 Entry/Exit를 신규진입/익절로 자동 치환하지 않는다.
4. Binance 현물 OHLCV와 BitMEX 계약 실행가격은 서로 다른 시장이다. 마커는 시각으로 봉에 붙이고 실행가격은 상세에 둔다.
5. 체결이 속한 봉 전체 OHLCV는 그 순간 미완성일 수 있다. 사전 분석은 완성된 과거봉만 사용한다.
6. 총 수량을 첫 체결 순간에 일괄 체결했다고 해석하지 않는다. 그룹에 중간 다른 주문이 섞인 경우 단순 차감/누적은 금지한다.
7. 5%/3% of future maximum은 사후 표본 분류이지 실시간 신호가 아니다.
8. 거래량 급증·윗꼬리/아랫꼬리만으로 검증된 진입 신호라고 부르지 않는다.
9. 성공/실패 반례를 함께 보존하며 트레이더가 항상 적절히 손절했다고 미화하지 않는다.
10. Core + Tactical 노출은 행동 해석 가설이다. 시장의 내부 원인·본인의 생각을 확정하지 않는다.

## 기존 자료의 특별한 주의사항
제공된 주문 이벤트 표에는 어떤 행에서 `qty_before + qty != qty_after`가 나타난다. 이는 첫·마지막 체결 사이 다른 주문이 겹칠 수 있기 때문이다. 원본을 재확인하지 않고 오류 수치로 자동 수정하거나 누락 주문을 만들어 넣지 않는다.

최초 입력은 전체 4년 원장 재검산 대신 이미 검산된 주문 끝점 자료를 사용한다. 미래 백테스트나 실제 투자 판단에는 별도 검증이 필요하다.
