# 구현 상태

## 구현 코드가 포함된 기능
- 표준라이브러리 Python 로컬 서버, SQLite, Windows 배치 실행기.
- CSV/gzip/ZIP 가져오기, 기존 AOA 끝점/이벤트/대표타임라인 어댑터.
- 실제 캔들 및 거래량, 6개 시간대, 날짜·포지션·주문 점프.
- 마커 그룹화/필터, 첫/마지막 체결 선택, 주문 상세/사전 특징.
- 사후 가설 분류와 원장 역할 분리.
- 메모 저장/태그, PNG 저장, 주문 CSV 추출.
- 완성 봉 단위 복기, 미래 봉·결과·사후 집계 마스킹.
- 요청 시 공개 Binance 1분봉 수집/로컬 캐시.
- Windows/Linux 자동 테스트, 프런트 로직 및 브라우저 검사 workflow.

## 아직 구현하지 않은 기능
- Tauri/PyInstaller 독립 EXE와 자동 업데이트.
- 원본 개별 execution 140만행에서 포지션을 재복원하는 새 엔진.
- 정확한 틱별 보유수량/평균단가 변화 곡선. 현재는 주문 구간 끝점만 표시.
- 여러 계약을 합친 계좌 총위험/헤지/실효 레버리지 재계산.
- 전체 패턴 유사도 검색·자동 규칙 발굴·원인 확정.
- 무한 스크롤 자동 페이지 로딩, 두 포지션 동시 비교, 차트 위 자유선 그리기.
- 사용자 PC에서 실제 전체 ZIP을 가져오는 전수 통합검사.

## 검증 근거
정확한 통과/실패 상태는 해당 커밋의 GitHub Actions를 따른다. 코드가 작성되었다는 사실과 실행 확인을 구분한다. 브라우저 스크린샷은 합성 테스트이며 고래의 실제 시장 분석 결과가 아니다.
