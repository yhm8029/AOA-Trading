# v0.2 — 재생·연도·시세 공백·퍼센트 수정

## 실행 중인 main 버전 업데이트

1. 기존 서버 창에서 Ctrl+C로 종료합니다. 기존 브라우저 탭도 닫습니다.
2. 성공한 CI의 실행 ZIP을 풉니다. 새 프로그램 파일로 기존 main 앱 폴더를 덮어쓸 수 있습니다.
3. **기존 `local-data/` 폴더를 삭제하거나 덮어쓰지 마세요.** 주문·분봉·메모 DB는 그대로 사용합니다. 다른 폴더에 설치했다면 종료 상태에서 기존 local-data 폴더를 새 앱 폴더로 복사합니다.
4. `start_windows.bat`를 실행합니다. 화면 상단에 **v0.2.0**이 보여야 합니다. 계속 v0.1이면 옛 서버가 실행 중인 것입니다.
5. 기존 파일을 다시 가져올 필요는 없습니다. 초기 화면은 2021년 **첫 관측 주문이 시작된** 포지션입니다. 전년도 이월 포지션은 체크박스를 켜야 포함됩니다.

별도 `feat/whale-viewer-v1`의 `data/aoa.sqlite3`는 다른 스키마입니다. 그 DB를 viewer.sqlite3로 이름만 바꿔 사용하지 마세요. 이번 변경은 사용자 스크린샷의 main/run.py/local-data 버전 기준입니다. 이전 브랜치를 병합/덮어쓰지 않습니다.

## 수정 내용

- Play, 복기 체크, 선택 주문 직전 버튼 모두 동일한 진입 직전 초기화를 사용합니다.
- 재생 슬라이더는 실제 완성 봉만 셉니다. 공백 수백 개를 기다리거나 빈 화면에서 계속 도는 대신 건너뛴 구간을 명시합니다. 시세 보완 중에는 자동 재생을 멈춥니다.
- 재생 시각·속도·이전 봉·다음 봉·선택 주문 재시작을 지원합니다. 시간봉을 바꿔도 복기 cutoff를 유지하며 아직 완성되지 않은 상위 봉을 공개하지 않습니다.
- 연도/방향/계약 변경은 목록과 선택 포지션을 함께 갱신합니다. 검색 결과가 없으면 이전 차트/성과를 지웁니다. 요청 경쟁으로 이전 차트가 새 선택을 덮어쓰지 못하도록 세대 번호와 AbortController를 씁니다.
- 일반 시간봉 전환은 비대칭 화면 중심이 아니라 선택한 주문/날짜 anchor를 유지합니다.
- 자동 보완(끄기 가능)은 Binance 공개 1분봉 중 **없는 분만** 요청하고 로컬에 캐시합니다. 네트워크를 기다리는 동안 SQLite 쓰기 잠금을 잡지 않습니다. 페이지별 저장으로 중단 이후 남은 구간부터 재개합니다.
- 성공 응답이어도 원본 공백/충돌이 남으면 완전하다고 표시하지 않습니다. 자동 재시도 무한 루프를 막으며 접근 제한은 우회하지 않습니다. HTTP 429의 Retry-After를 지킵니다.
- 마우스 호버 카드와 상단 OHLCV에 봉 시가→종가 %, 전봉 종가 대비 %, (고가−저가)/시가 %를 표시합니다. 앞 봉이 없으면 전봉 대비는 미확보입니다.
- 감량 주문마다 가격변화율을 타임라인에 표시합니다. 포지션 카드에는 수량가중 감량 가격성과와 원장 BTC 순손익을 구분합니다.
- 참고 증거금을 직접 입력한 경우에만 원장 순손익/입력 증거금 ROI를 계산합니다. 실제 증거금을 추측하거나 레버리지 5배를 임의 적용하지 않습니다.
- 차트 hover/리플레이/성과·증거금/메모·PNG/가져오기/반응형 화면을 Chromium에서 검사합니다.

## 퍼센트의 의미

봉: `(종가/시가 - 1) × 100`.
전봉 대비: `(종가/직전 연속 봉 종가 - 1) × 100`.
고저폭: `(고가−저가)/시가 × 100`.

**감량 가격성과***: 제공된 Exit 주문에서 `수량 × 방향부호 × (그룹 산술평균가격/주문 직전 평균단가 - 1) × 100`의 수량가중 평균입니다. 평균가가 없으면 첫 가격을 참고값으로 씁니다. 한 주문 동안 평균단가가 바뀔 수 있으므로 **그룹 참고 근사값**이며 정확한 전체 실현수익률이 아닙니다. 사용된 주문 수와 수량 커버리지를 함께 표시합니다. 제공된 자료에 빠진 주문이 없는지는 이 수치만으로 확인할 수 없습니다.

원장 순손익은 입력에 제공된 BTC 값입니다. 일관되지 않은 여러 값이 관측되면 성과/ROI 계산을 막습니다. 증거금 분모가 없으면 ROI는 미확보입니다. 사용자 입력 증거금 ROI도 증거금 변동·입출금·복리 기준 계좌 수익률과 다릅니다.

**BitMEX XBTUSD 역계약 PNL을 선형 USDT PNL로 재계산하지 않습니다.** 단순 방향환산 가격차를 BTC 실현손익으로 변환하거나 레버리지를 곱하지 않습니다. 분할체결 원장은 아직 이 앱의 신규 재회계 대상이 아닙니다.

## 검증 한계

로컬 실행 환경 오류로 이 개발 세션에서 사용자의 원본 ZIP 전수 가져오기를 수행하지 못했습니다. CI는 합성 거래/시세로 UI·API 회귀를 검사하며, 별도의 공개 시장 probe는 실제 Binance 2021-01-03 1분봉을 받아 작업 사본에 구간 공백을 만든 후 실제 API로 복원하는 검사입니다. 공개 probe 성공도 고래 원장 전체 검산이 아닙니다. CI의 public-market-probe.json 상태를 확인하세요.

프로젝트의 최종 연구 목표(패턴 자동 분류, 개별 execution 재회계, 계좌 전역 노출, EXE 등)가 전부 완성되었다는 뜻이 아닙니다. 이번 범위는 사용자가 제보한 뷰어 오류와 그 주변 회귀 수정입니다.
