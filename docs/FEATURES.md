# 기능 명세 — v0.2

사용자에게 필요한 것은 일반 매수 신호가 아니라 실제 고래 주문을 실제 캔들 위에서 확인하는 화면입니다.

## 차트 탐색
- 1분/5분/15분/1시간/4시간/일봉. Binance 현물 OHLCV, 거래량 pane, 우측 가격축.
- 주문/날짜 anchor를 유지하며 시간봉 전환. 연도 선택은 목록과 현재 포지션을 함께 갱신.
- 첫 관측 진입 연도 기준(기본), 전년도 이월 포함(선택), ID/계약/방향/결과 필터.
- 같은 봉 같은 방향/행동은 묶음, 개별 주문 타임라인은 보존. 마커가 표시 한도를 넘으면 생략 개수 안내.
- 봉 호버: OHLCV, 시가→종가 %, 직전 연속 봉 종가 대비 %, 고저폭/시가 %, 상대 거래량 RV20.
- 진입으로/주문으로 이동, 이전·다음 주문/포지션, 전체 포지션 보기. 긴 포지션은 시간봉 확대, 한 번의 창은 최대 179일.

## 복기
- Play/체크/재시작이 같은 초기화 사용: 선택 주문 또는 진입 기준 3봉 전.
- 실제 완성 봉만 재생. 누락 구간 건너뛰기와 실제 시세 보완을 명확히 구분.
- 속도 0.5/1/2/5/10배, 이전/다음 봉, 실제 봉 인덱스 슬라이더.
- 시간봉을 바꿔도 cutoff 유지. 해당 시각에 완성되지 않은 상위 봉은 보여주지 않음.
- 빈 상위 시간봉에서 이전/다음/재생을 눌러도 오류가 나거나 시간이 앞으로 점프하지 않음.
- 미래 주문·최종 손익·ROI·사후 분류·주문 최종 수량·참고 가격선 숨김.
- 로딩 중 재생 차단, 이전 비동기 콜백이 새 재생 타이머/포지션을 덮지 못하게 세대 번호 확인.

## 시세 공백
- 누락된 1분만 자동/수동 보완, 켜기/끄기, 진행·중단, 로컬 캐시.
- 공개 거래쌍/기간만 전송. 원장·메모 전송 없음.
- 검증 후 페이지별 저장, 실패한 뒤 남은 구간만 재개. 네트워크 대기 중 DB 쓰기 잠금 없음.
- 원본 공백/충돌/접근제한은 안내. 없는 봉을 만들거나 가격 보간하지 않음.

## 성과/메모
- 원장 BTC 순손익, 감량 가격성과 참고 %, 선택적으로 입력 증거금 참고 ROI를 구분.
- 계산 정의와 관측 감량 커버리지 표시. 정확한 증거금이 없으면 실제 ROI는 미확보.
- 기존 local-data DB와 메모 유지, 태그/메모 저장, 미저장 메모 경고, PNG/CSV 내보내기.
- 좁은 창에서 우측 정보 패널을 아래로 재배치하여 수평 화면 밖으로 숨지 않게 함.

완료하지 않은 연구/배포 항목은 STATUS.md를 참고하세요. 이 명세의 구현 여부와 사용자 전체 원장 검산은 별개입니다.
