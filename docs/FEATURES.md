# 기능명세 v0.1

## 목표
TradingView 스타일의 실제 캔들 위에 고래 주문을 표시하고, 수년 전 포지션도 스크롤 없이 찾아 복기한다. 자동매매/실시간 추천 신호를 만드는 프로젝트가 아니다.

## 입력 / 출력
입력은 기존 AOA 가공 CSV, 정규화 캔들 gzip, 이를 담은 ZIP이다. 원본 execution ledger의 재구성은 별도 단계다.
출력은 인터랙티브 차트, 포지션별 주문표, 로컬 연구 메모, PNG 캡처, 주문 CSV다.

## 기능과 수용 기준
1. 데이터 가져오기: 여러 파일 선택, ZIP 내부 스트리밍 읽기, 진행 상태, SHA-256 동일 파일 중복 방지, 명확한 실패 메시지. 원본 불변.
2. 포지션 탐색: 계약/연도/방향/결과/ID 검색, 이전·다음 버튼. 결과가 없는 거래는 Unknown. 전년도 시작 이월 포지션도 겹치는 연도로 조회.
3. 캔들: 1/5/15분·1/4시간·일봉. 1분 원본으로 완전한 그룹만 집계. 빈 분을 가상 가격으로 채우지 않음.
4. 거래량: 같은 시간축의 별도 하단 pane. 기준자산 거래량, OHLC 및 현재 완성 봉 거래량/직전20봉 평균 표시.
5. 마커: 주문 첫 또는 마지막 체결을 포함하는 봉에 표시. 존재하지 않는 봉으로 스냅하지 않음. 같은 봉·행동·방향은 합산하고 원래 개별 주문은 오른쪽 목록에 유지.
6. 상세: 마이크로초 원본시각, 첫·마지막, 산술/역수가중 가격, 그룹 수량, 시작전·끝난후 수량, 시작전 평균단가, 스톱가격, 사전 가격·거래량 필드, 원본 주문ID.
7. 표시 필터: 최소수량, 진입/감량, 기존 CUT/FLIP 가설 별도 토글. 미래 최대 보유량 기준을 새로운 기본 분류에 도입하지 않음.
8. 복기: 완성 봉만 순차 공개. 사후 분류·성과·최종 주문 수량 숨김. 틱 복제가 아닌 완성 봉 단위 학습.
9. 메모: 포지션별 text/tags SQLite 저장. HTML 실행 없이 text로 렌더링.
10. 시세 보완: 사용자가 누른 경우에만 고정된 Binance 공개 API 경로 사용. 최대20,000분, 페이지당1000봉, 제한상태 우회 금지, 실패 시 트랜잭션 롤백.
11. 로컬 보안: loopback 바인딩, Host/Origin 검증, write token, 512MB 업로드 제한, ZIP 경로 검증.

## 용어
`ENTRY`=시작전 보유량 0이 확인된 주문. `ADD`=시작전 보유량이 있는 증가. 수량 미확보는 `INCREASE`(진입/추가).
`STOP`=원장의 명시적 Stop 계열 주문 유형. `CLOSE`=마지막 끝점이 확보되고 끝난후 수량 0인 종료 주문.
`TP/LOSS_REDUCE`=원장 평균단가 대비 그룹평균/첫 가격의 유불리. 순손익과 구분.
`CUT?/전환?`=기존 연구 분류를 옵션으로 표시하는 가설. 본인의 의도 확인 아님.
