# AOA Whale Viewer v0.3.0 — 매매 해설·복기 통합 배포판

이번 배포 범위는 캔들·거래량·기록된 주문 위치·근거 기반 해설을 함께 보는 로컬 연구 앱입니다. 트레이더의 속마음 또는 미래 수익을 확정하는 자동매매 프로그램이 아닙니다.

## 업데이트

1. 실행 중인 이전 앱 콘솔을 Ctrl+C로 종료합니다.
2. `AOA-Whale-Viewer.zip`을 새 폴더에 압축 해제합니다.
3. 기존 앱의 `local-data` 폴더 전체를 새 폴더로 복사합니다. 복사 전 원본 폴더를 별도 백업하고, 원본을 삭제하지 마세요.
4. 새 폴더의 `start_windows.bat`를 실행합니다. Python 3.10 이상이 필요합니다.
5. 화면과 서버 표시가 모두 v0.3.0인지 확인합니다. 기존 화면이 남으면 Ctrl+F5로 새로고침합니다. 다른 앱 폴더가 실행 중이라는 경고가 나오면 해당 콘솔을 먼저 종료합니다.

이미 가져온 주문·시세·연구 메모는 local-data와 함께 유지합니다. 원본 ZIP을 처음부터 다시 넣을 필요는 없습니다. 독립 EXE 또는 Python 포함 설치판은 아닙니다.

## 반영한 동작

- 포지션 선택 시 최초 관측 주문으로 이동. 짧은 포지션은 진입부터 감량까지 함께 표시합니다.
- 최소 수량 기본값 0. 최초 진입·마지막 관측 감량·선택 주문은 수량 필터로 지우지 않습니다.
- 수량 필터로 차트에서 가린 주문도 오른쪽 전체 타임라인에는 남습니다.
- 수량 입력 후 바로 주문을 클릭할 때 blur/change 재렌더가 클릭을 삼키던 문제 수정.
- 주문마다 첫 체결 이전 완성 캔들·거래량, 보유량과 평균단가, 앞선 완료 주문을 연결한 해설.
- 관측 사실 / 유력한 해석과 다른 가능성 / 반대 근거 / 자료 한계 분리.
- 1·5·15·60·240·1440분 배경 표 및 근거 봉 바로 보기.
- 재생이 주문을 포함한 완성 봉에 도달하면 마커·주문 목록·해설 갱신. 주문에서 자동 일시정지 옵션.
- 복기 중 미래 주문·사후 손익·완료되지 않은 주문의 최종 집계값 숨김.
- 15분봉을 포함한 각 시간봉 구간의 누락 1분봉 보완 후 재집계. 누락·충돌 수 표시, 인위적 보간 없음.
- 해설용 사전 48시간 시세 보완 버튼. 원시 캔들 구간이 좁아 배경이 부족한 경우에 사용합니다.
- 봉 등락률·전봉 대비·고저폭·거래량·상대 거래량 호버 표시.
- 감량 가격성과 참고값과 원장 BTC 순손익, 사용자가 확인해 입력한 증거금 기준 ROI 분리.
- PNG·CSV·해설 JSON 내보내기, 메모 저장, 연도/이월·롱/숏 검색.
- 화면 크기에 따른 배치 및 이전 화면/서버 버전 불일치 안내.

## 사용

포지션 선택 → 오른쪽 주문 또는 차트 마커 클릭 → 해설 확인.
복기는 첫 진입으로 → 선택 주문 직전 → 주문에서 멈춤 선택 → 재생 순서입니다.
15분봉이 비면 현재 구간 누락 수와 충돌 수를 확인하고 시세 보완을 실행합니다. 원본 거래소의 공백이나 차단은 가짜 캔들로 감추지 않습니다.

## 해설의 범위

이 버전은 로컬 규칙 기반 해설입니다. API 키나 유료 LLM 호출이 없습니다. 추세 지속, 눌림, 단기 역행, 범위 끝, 이탈 후 복귀, 큰 거래량 대비 가격 진행, 감량 후 재확대, 이익 회수, 위험 감소, 스톱 기록, 추가 전 규모 복귀 등을 관측 조건에 맞을 때만 후보로 제시합니다. 임계치는 연구 초기값이지 검증된 진입 공식이 아닙니다. 근거가 부족한 주문에는 이유 미확인을 표시합니다.

원본 체결시각은 의사결정·주문 제출 시각과 다를 수 있습니다. Binance 현물 OHLCV와 BitMEX 체결가격은 별개입니다. 첫/마지막 끝점만 있는 주문의 중간 체결 경로는 복원했다고 표시하지 않습니다. `감량 가격성과*`는 제공된 감량 주문의 수량가중 가격 참고값이며, 전체 수수료·펀딩 포함 수익률 또는 계좌 수익률이 아닙니다.

## 검증 범위

배포는 Windows/Linux Python 3.10·3.13 단위 검사와 Chromium 브라우저 3종 검사 성공 뒤에만 생성합니다. 브라우저 회귀 자료는 명시적 합성 데이터입니다. 작은 포지션, 필터 후 실제 클릭, 해설, 15분봉 누락 보완, 주문 자동 일시정지, 미래 주문 API 차단, 반응형 배치를 검사합니다.

공개 Binance 시세 보완 검사는 별도 결과로 남기며 네트워크 실패를 성공으로 숨기지 않습니다. 사용자의 전체 거래 ZIP 전수 통합검산을 완료했다는 의미는 아닙니다. 전체 패턴의 승리·실패 비교, 엄밀한 개별체결 회계, 증거금 이력, 전체 포지션 상태 머신 검증은 장기 연구 항목입니다.

ZIP에는 개인 거래파일·local-data·메모·비밀키를 포함하지 않습니다. `release-manifest.json`은 소스 커밋과 파일별 SHA-256을, `.zip.sha256`은 실행 ZIP 해시를 기록합니다.
